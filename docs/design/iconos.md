# Icons / Íconos

- Links of a profile (website, Instagram, Facebook, TikTok, YouTube) and the WhatsApp link: Bootstrap Icons, through the `react-bootstrap-icons` package (MIT license). One colour: they follow the text colour (light and dark mode). The marks belong to their owners; each network's brand rules apply.
- Enlaces de un perfil (web, Instagram, Facebook, TikTok, YouTube) y el de WhatsApp: Bootstrap Icons, con el paquete `react-bootstrap-icons` (licencia MIT). De un solo color: siguen el color del texto (modo claro y oscuro). Las marcas son de sus dueños; valen las reglas de marca de cada red.
- Mail, phone and service-mode icons: simple line icons drawn for this project. / Íconos de mail, teléfono y modalidad: íconos de línea simples dibujados para este proyecto.
